# Claim-to-evidence register

| Candidate claim | Required new evidence | Explicit boundary |
|---|---|---|
| Policies learn actual tasks | Nonzero actor parameter updates, checkpoint evaluation, delivered items | Optimizer activity alone does not establish improvement |
| Typed overlaps improve decisions | Seed-paired PCI vs penalty/consensus contrasts; full coefficient sweep | May be null or negative; no advance promise |
| Institutional compatibility is computed | Action-grounded residuals, gradient/unit tests, fixed-state spectral argument | Not H^1; not safety or infeasibility by itself |
| Admission enforces operational rules | Independent monitor checks, shielded traces, proof-before-execution tests | Central trusted state/executor; no physical robot guarantee |
| Certificates are real | Server Circom compile, actual snarkjs proof/verify, Poseidon/public-ABI parity and negative tests | Local Python-only tests do not establish this |
| Cryptographic overhead is practical | Actual paired timings, sizes and persisted proofs; disclosed setup assumptions | 96 transitions, not full-scale production throughput |
| Generalization in agent count | Fixed-model 2/8/12-agent held-out tests, seed-level intervals | Across-episode population change, not dynamic churn |
| Contradictions can be diagnosed | Specified affine-cycle test with numerical + analytical + LP oracle | Not automatic diagnosis from high neural loss |
| New paper is supported | Traceable results for every reported claim, complete tables and limitations | A completed run does not guarantee acceptance |

NOT IMPLEMENTED / DO NOT CLAIM: learned restriction maps, joint optimization of
institutional policy budgets, independent second real-world domain, actual robots,
private multi-party proving, proof of policy inference or sheaf energy, continuous
collision avoidance, dynamic joining/leaving, recursive SNARKs, 10x batch speedup,
DP guarantees, human trust studies, measured superiority before results.

The old 94%, 73%, and lightweight microsecond latencies are excluded from all new
summary tables. Do not merge the earlier contaminated CSVs with this experiment.
